# Exports

`operia/exports` is the canonical export service for OPERIA Forensic Tracing.

Supported canonical formats:

- JSON;
- CSV;
- Markdown;
- PDF;
- report JSON;
- report CSV;
- report Markdown;
- report PDF.

Forensic controls:

- every canonical export calculates SHA-256;
- every canonical export calculates MD5 for compatibility with legacy workflows;
- every canonical export creates a sidecar `.manifest.json`;
- every canonical export stores an `ExportManifest` database record;
- every canonical export writes an audit entry.

Manifest fields:

- product;
- export type;
- filename;
- file path;
- generated timestamp;
- generated by;
- organization id;
- user id;
- case id;
- report id;
- SHA-256;
- MD5;
- human review warning;
- chain-of-custody note.

Canonical routes:

- `POST /api/exports/json`
- `POST /api/exports/csv`
- `POST /api/exports/markdown`
- `POST /api/exports/pdf`
- `GET /api/exports/reports/{report_id}/{fmt}`
- `GET /api/exports/manifests`
- `GET /api/exports/manifests/{manifest_id}`
- `GET /api/exports/manifests/{manifest_id}/download`
