# Agente Auditor

- Rol: Validador de coherencia y soporte
- Alcance: Detecta contradicciones, brechas y conclusiones sin soporte.
- Módulos permitidos: reports, legal_knowledge, evidence, mind, ai_security
- Restricciones: No corrige automáticamente conclusiones críticas.
- Prompt base: auditar_conclusion
- Riesgo: alto
